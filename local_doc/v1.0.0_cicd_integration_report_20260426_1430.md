## 三、技术实现细节

### 3.1 CMake 构建选项

```cmake
-DJW_BUILD_SHARED=ON    # 构建共享库
-DJW_BUILD_STATIC=ON    # 构建静态库
-DJW_BUILD_TESTS=ON     # 构建测试
-DJW_BUILD_EXAMPLES=ON  # 构建示例
-DJW_ENABLE_SIMD=ON     # 启用 SIMD 优化
```

### 3.2 跨平台支持

| 平台 | 编译器 | 构建工具 | 特殊功能 |
|------|--------|----------|----------|
| Linux | GCC/Clang | Make, Ninja | AddressSanitizer, 覆盖率 |
| macOS | Apple Clang | Make, Ninja | Universal Binary |
| Windows | MSVC, MinGW | Visual Studio, Ninja | 交叉编译 |
